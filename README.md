# Recetario digital — Vicky Café

Sitio web estático creado con HTML5, CSS3 y JavaScript puro.

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: diseño responsive.
- `app.js`: navegación, búsqueda y modales.
- `data.js`: datos extraídos del Excel original.

## Uso
1. Abre `index.html` en Chrome, Edge o Firefox.
2. Usa el menú para entrar en Platos, Sub recetas o Insumos.
3. Usa el buscador para localizar preparaciones o ingredientes.
4. Haz clic en un plato/sub receta para ver cantidades y costos registrados.

## Actualizar el recetario
Cuando cambie el Excel, hay que volver a convertir sus hojas a `data.js`. La web no modifica el Excel original.
